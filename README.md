## Fallout 3
[Waters of Life](https://github.com/zpok3/Waters-of-Life) - Waters of Life is a lightweight vanilla plus Wabbajack mod list for Fallout 3. It features essential vanilla bug fixes, performance optimizations, restored cut content, and a few gameplay features you might be used to from more modern games.
